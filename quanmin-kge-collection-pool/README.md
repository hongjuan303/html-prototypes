# 合集池新增全民K歌：原型＋需求说明

公开地址：https://hongjuan303.github.io/html-prototypes/quanmin-kge-collection-pool/

沿用 `oppo-collection-pool` 的左侧后台原型、右侧 PRD 栏。画布保持后台表格尺寸，小屏可横向滚动；弹窗适配当前窗口。

## 可体验流程

- 池类型筛选、新建与改名、元素增删、自动添加规则示例、批量添加/粘贴导入、启停。
- 渠道资料维护、条件必填校验、125 集按 100＋25 拆批模拟推送。
- 历史记录、明确失败分集重试、超时待确认、集序与付费独立同步。

所有数据仅保存在本页面内存，刷新重置；按钮不调用真实渠道接口、不上传文件。示例内容不代表实际业务数据。演示校验不验证渠道权限、真实文件、待确认的分类和封面规则。

## 来源与边界

- 页面参考：[OPPO 原型](https://hongjuan303.github.io/html-prototypes/oppo-collection-pool/)。
- 接口来源：用户提供的《声播统一接入内容合作 API—短剧》PDF（15 页），原文链接在右侧说明栏。源 PDF 未包含在发布文件中。
- 文档未明确列出全民K歌，需要确认账号分发权限；成功仅表示接口接收，不能表示已分发、审核或上架。
- 右侧是目标需求；分类、封面、合同、付费、重试和清空语义等需联调确认。部分目标状态仅在说明中列出。

## 已确认的字段映射（2026-09-18）

- 制作预算取合集的成本（万元）；全网发布时间取公开时间。
- 全民K歌发布时间由系统按实际发起推送的时间生成；重试／更新覆盖语义待确认，样例暂保留首次时间。
- 短剧使用男演员＋女演员姓名，漫剧使用男角色＋女角色，合并去重。
- 多个题材标签默认按原顺序取第一个，再映射一级分类ID；此规则不适用于二级分类。
- 资料弹窗自动展示以上来源，推送记录显示渠道和全网发布时间。右侧说明列出完整合集字段映射。
- 是否首发、特殊类型归属、二级分类、备案附件及平台规范仍标记待确认。
