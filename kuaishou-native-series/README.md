独立产品交互原型，使用虚构数据演示绿台合集批量创建快手原生短剧、补齐资料、上传分集、提交审核和失败恢复。

- 在线原型：[GitHub Pages](https://hongjuan303.github.io/html-prototypes/kuaishou-native-series/)
- 源码目录：[hongjuan303/html-prototypes](https://github.com/hongjuan303/html-prototypes/tree/main/kuaishou-native-series)
- 纯原型：`index.html`
- 产品说明与待确认项：`review.html`
- 说明常驻在原型画布右侧，随整体画布横向滚动查看，关键区域序号与右侧逐项对应，随列表、账号选择、资料配置、确认上传和编辑页面切换；顶部「原型说明」仅定位到右侧说明，不再收起/展开。说明内容由`prototype-notes.js`维护，独立说明页仅保留作补充材料。
- 说明遵循工作区`99-模板/产品原型说明标准.md`：橙色#F28C18标题与序号、页面说明＋原型说明、分层条目及筛选/配置、列表、操作分组；说明栏520px，窄窗口440px，左侧原型保持完整宽度，说明追加在其右侧，整体画布可横向滚动。
- 数据：`data.js`；校验及状态模型：`model.js`、`record-model.js`；界面与交互：`app.js`
- 上传草稿与记录存储在当前浏览器的 `kuaishou-native-series-v1`，账号管理数据单独存储在 `kuaishou-native-series-accounts-v1`；不调用任何业务API。
