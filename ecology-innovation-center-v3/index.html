# 原型说明

  • 背景：面向政府、产业伙伴、院校及短剧从业者，集中展示容量万相的城市合作成果与生态服务能力。
  • 目标：让政府看见落地成果，让创作者看见合作机会，并形成项目合作、社区加入和赛事参与入口。
  • 适用端：本期仅适配PC端，推荐评审分辨率为1440×900及以上。

# 首页轮播

# 功能说明

  1. 数据来源：Banner由业务人员在绿台「瀑布流轮播图」中配置，前台按上架状态、有效时间及排序结果展示，不限定固定数量。
  2. 展示内容：支持图片或视频素材；标题、素材类型、素材文件、有效时间及跳转方式均取绿台配置。
  3. 轮播规则：存在多条有效Banner时默认每3秒自动切换；鼠标移入暂停，移出后继续。
  4. 手动切换：存在多条有效Banner时展示左右箭头与底部指示器，数量随有效Banner数量动态生成。
  5. 点击效果：绿台配置跳转链接时，点击Banner按配置地址跳转；未配置跳转链接时，Banner仅展示且不响应点击。
  6. 兜底规则：无有效Banner时隐藏轮播区域，页面后续模块上移展示。

交互备注：仅可跳转的Banner展示鼠标悬停反馈；轮播切换保留平滑视觉过渡。当前演示中的雁荡山杯已结束，Banner入口展示「已结束」，不响应点击或跳转；其他Banner仍按绿台跳转配置执行。

# 容量短剧产业协同网络建设

# 展示内容

  • 产业生态建设：场地、内容创制平台、算力、版权库、发行、出海与产业订单。
  • “微短剧+”精品内容：联动文旅、非遗、科普和公益项目，开放地域内容订单。
  • 微短剧创作大赛：联合伙伴发布创作命题、流量扶持及作品奖励。
  • 产教融合实践：联合高校开设实践专班，提供订单、算力和孵化资源。

# 交互说明

  • 四个能力卡片固定单行展示，无先后顺序。
  • 卡片右上角分别展示「生态基座、城市共创、创作者连接、人才共育」标签。
  • 本期卡片仅展示内容，不设置跳转。

# 生态合作地图

# 地图规则

  1. 初始展示全国地图及项目标识，不展示右侧项目详情。
  2. 支持滚轮、缩放控件和拖拽操作，最大放大至区县级行政边界。
  3. 不同项目类型使用不同图标：精品短剧、产业空间、校企合作、创作赛事、即将呈现。
  4. 点击地图标识后地图向左收缩，右侧展示对应城市或区县的项目详情。

# 项目层级口径

  • 精品短剧按最小行政层级展示：区县项目仅显示在区县层级，市级项目仅显示在市级层级。
  • 同一地区存在多个项目时，右侧按项目列表展示并支持切换。
  • 精品短剧封面统一使用长宽比9:16。

# 操作项

  • 精品短剧：点击封面打开高光片花弹窗；点击「我要合作」打开合作申请表单，弹窗不展示「申请合作《xxx》」文案。
  • 产业空间：点击「我要加入」打开空间加入表单。
  • 校企合作：点击「我要合作」打开合作申请表单。
  • 创作赛事：雁荡山杯原「我要参赛」按钮改为「已结束」，按钮不可点击，不打开报名表单或跳转赛事官网；大广赛保留「敬请期待」状态。
  • 即将呈现：展示区域合作预告，不提供提交入口。

# 线上OPC创作社区

# 核心权益

  • 平台提供剧本、漫剧制作工具和合作团队算力折扣。
  • 成片后可由平台代发行，支持保底加分成、收益分成或版权买断。
  • 社区达到一定规模后，平台可协助对接当地政府及创业扶持资源。

# 城市社区规则

  1. 每个城市仅设置一个官方线上OPC社区。
  2. 当前不存在任何线上OPC社区时，隐藏「已建立的城市社区」模块。
  3. 存在已建立社区时展示「已建立的城市社区」模块；多个城市社区保持单排展示，支持鼠标横向滑动查看。
  4. 已有社区显示城市名称、成员人数及「申请加入」按钮。
  5. 未建立社区显示「等待首位发起人」，用户可申请创建。
  6. 申请通过后，成员人数由正式数据接口实时更新；原型暂使用演示数据。

# 申请加入操作

  1. 点击城市社区卡片中的「申请加入」，打开居中的申请弹窗。
  2. 先选择「个人创作者」或「创作团队 / 企业」，分别展示对应字段；按业务 PDF，两种身份均不填写「所在城市」。城市社区或产业空间入口仅保留申请来源，不等同于申请人所在地。
  3. 点击「取消」或关闭图标，关闭弹窗且不保存本次填写内容。
  4. 点击「提交入驻申请」时校验当前身份下的必填项、手机号及多选项；详细字段见下方「申请表单」章节。
  5. 当前原型仅模拟提交成功，不生成后台记录、不更新成员人数；正式接入后，申请进入待审核流程，成员人数仅在审核通过后更新。

# 申请表单

修改日期：2026-09-11 · V1.2

本次替换旧版通用申请表单说明。字段依据《生态创新版块合作表单设置.pdf》及当前本地原型整理，包含 OPC 入驻、校企合作、精品内容合作三类业务表单；原型与需求仍存在的差异统一列在本章末尾，不视为已完成能力。

# 入口与适用对象

表单触发入口适用对象 / 当前状态
AI 影视 OPC 社区入驻产业空间「我要加入」；城市社区「申请加入」或「申请共建 OPC 社区」个人创作者、创作团队 / 企业；学生长期接单或入驻生态使用此表单。
产教融合 / 校企合作地图校企合作项目「我要合作」高校院系负责人；学生个人参与创作接单引导至 OPC 个人入驻。
“微短剧+”精品内容合作地图精品短剧项目「我要合作」个人、团队、企业、地方文旅 / 事业单位；弹窗不展示「申请合作《xxx》」标题。

# 通用填写与交互规则

  1. 呈现：三类表单均在当前页弹窗展示，不强制新开页面；长表单在弹窗内纵向滚动。展示业务说明、适用对象提示、当前表单的独立提交按钮。
  2. 必填：必填项使用星号标识；必填单选须选一项，必填多选须至少选一项。所有表单提交前须勾选「我已阅读并同意隐私政策，授权平台用于本次申请审核与业务联系」。
  3. 格式：手机号为 11 位中国大陆号码，首位为 1、第二位为 3–9；邮箱使用邮箱格式校验；人数和工位数为正整数，最小为 1，选填数字为空时不校验。
  4. 文本与链接：当前文本、简介和作品链接未设置统一字数上限；不沿用旧表的「业务范围最多 300 字」。链接当前为文本输入，未校验 URL 可访问性；信用代码当前未做长度或校验位验证。
  5. 附件：当前为单文件选择，展示所选文件名，仅演示选择状态；未实际上传，未限制扩展名、大小或实施安全检测。正式上传格式、容量及失败重试规则待接入时确认。
  6. 条件字段：按所选身份和答案显示相应字段；需求上隐藏分支不参与必填校验或提交。切换身份不自动清空已填内容，重新打开弹窗会重置表单；现有条件校验差异见章末。
  7. 取消：点击「取消」、关闭图标、遮罩或按 Esc 关闭弹窗；不保存草稿，重新打开不恢复上次填写。
  8. 提交：校验失败保留弹窗并提示对应字段，多选缺失提示「请至少选择一项」；通过后按钮显示「提交中...」并禁用，当前约 900 毫秒后演示各表单成功文案。
  9. 结果：成功页点击「完成」关闭弹窗。当前无真实接口、附件存储、数据落库或审核触发；正式接入时提交失败应保留填写内容、恢复按钮并允许重试，不能直接显示成功。

# 原型说明

2026-08-24 选择应用为“AI漫剧”且类型为“生态创新中心”时，隐藏“国内、海外”内容版本Tab。

○ 筛选项

  • 选择应用：下拉单选，选择“AI漫剧”。

  • 满足以上组合时，配置内容不区分国内和海外，页面不展示内容版本Tab。
