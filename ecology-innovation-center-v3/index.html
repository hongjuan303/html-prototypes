# 原型说明

  • 背景：面向政府、产业伙伴、院校及短剧从业者，集中展示容量万相的城市合作成果与生态服务能力。
  • 目标：让政府看见落地成果，让创作者看见合作机会，并形成项目合作、社区加入和赛事参与入口。
  • 适用端：本期仅适配PC端，推荐评审分辨率为1440×900及以上。

# 首页轮播

# 功能说明

  1. 数据来源：Banner由业务人员在绿台「瀑布流轮播图」中配置，前台按上架状态、有效时间及排序结果展示，不限定固定数量。
  2. 展示内容：支持图片或视频素材；标题、素材类型、素材文件、有效时间及跳转方式均取绿台配置。
  3. 轮播规则：存在多条有效Banner时默认每3秒自动切换；鼠标移入暂停，移出后继续。
  4. 手动切换：存在多条有效Banner时展示左右箭头与底部指示器，数量随有效Banner数量动态生成。
  5. 点击效果：绿台配置跳转链接时，点击Banner按配置地址跳转；未配置跳转链接时，Banner仅展示且不响应点击。
  6. 兜底规则：无有效Banner时隐藏轮播区域，页面后续模块上移展示。

交互备注：仅可跳转的Banner展示鼠标悬停反馈；轮播切换保留平滑视觉过渡。

# 容量短剧产业协同网络建设

# 展示内容

  • 产业生态建设：场地、内容创制平台、算力、版权库、发行、出海与产业订单。
  • “微短剧+”精品内容：联动文旅、非遗、科普和公益项目，开放地域内容订单。
  • 微短剧创作大赛：联合伙伴发布创作命题、流量扶持及作品奖励。
  • 产教融合实践：联合高校开设实践专班，提供订单、算力和孵化资源。

# 交互说明

  • 四个能力卡片固定单行展示，无先后顺序。
  • 卡片右上角分别展示「生态基座、城市共创、创作者连接、人才共育」标签。
  • 本期卡片仅展示内容，不设置跳转。

# 生态合作地图

# 地图规则

  1. 初始展示全国地图及项目标识，不展示右侧项目详情。
  2. 支持滚轮、缩放控件和拖拽操作，最大放大至区县级行政边界。
  3. 不同项目类型使用不同图标：精品短剧、产业空间、校企合作、创作赛事、即将呈现。
  4. 点击地图标识后地图向左收缩，右侧展示对应城市或区县的项目详情。

# 项目层级口径

  • 精品短剧按最小行政层级展示：区县项目仅显示在区县层级，市级项目仅显示在市级层级。
  • 同一地区存在多个项目时，右侧按项目列表展示并支持切换。
  • 精品短剧封面统一使用长宽比9:16。

# 操作项

  • 精品短剧：点击封面打开高光片花弹窗；点击「我要合作」打开合作申请表单。
  • 产业空间：点击「我要加入」打开空间加入表单。
  • 校企合作：点击「我要合作」打开合作申请表单。
  • 创作赛事：点击「我要参赛」新窗口打开赛事官网。
  • 即将呈现：展示区域合作预告，不提供提交入口。

# 线上OPC创作社区

# 核心权益

  • 平台提供剧本、漫剧制作工具和合作团队算力折扣。
  • 成片后可由平台代发行，支持保底加分成、收益分成或版权买断。
  • 社区达到一定规模后，平台可协助对接当地政府及创业扶持资源。

# 城市社区规则

  1. 每个城市仅设置一个官方线上OPC社区。
  2. 当前不存在任何线上OPC社区时，隐藏「已建立的城市社区」模块。
  3. 存在已建立社区时展示「已建立的城市社区」模块；多个城市社区保持单排展示，支持鼠标横向滑动查看。
  4. 已有社区显示城市名称、成员人数及「申请加入」按钮。
  5. 未建立社区显示「等待首位发起人」，用户可申请创建。
  6. 申请通过后，成员人数由正式数据接口实时更新；原型暂使用演示数据。

# 申请加入操作

  1. 点击城市社区卡片中的「申请加入」，打开居中的申请弹窗。
  2. 弹窗自动带入并锁定所选城市，用户填写团队或公司名称、团队人数、联系人、联系电话、业务范围等信息。
  3. 点击「取消」或关闭图标，关闭弹窗且不保存本次填写内容。
  4. 点击「提交申请」时校验必填项及手机号格式；校验失败时保留弹窗并提示对应字段。
  5. 校验通过后展示「申请已提交」结果，后台生成待审核记录；正式成员人数仅在审核通过后更新。

# 申请表单

字段形式规则
团队或公司名称文本输入必填
所在城市文本输入必填；从城市卡片进入时自动带入并锁定
团队人数数字输入必填；正整数
联系人文本输入必填
联系电话手机号输入必填；11位中国大陆手机号
业务范围多行文本必填；最多300字
意向合作模式下拉单选暂不确定、保底加分成、收益分成、版权买断
代表作品文本输入选填；填写作品链接

校验提示：必填项缺失或手机号格式错误时，不允许提交并在对应字段显示校验状态。
