# OPPO 合集池添加素材

入口：合集池管理 → OPPO行更多 → 查看合集信息 → 合集行「添加素材」→ 当前合集二级素材页。列表展示已添加素材，通过「新增素材」继续本地上传。

预览地址：<https://hongjuan303.github.io/html-prototypes/oppo-material-management/>

## 当前交互

- 本地上传一个或多个视频，逐条维护标题、简介、关联集数、连续裁剪起始时间、排序、上下架状态和封面。不从现有素材库选择。
- 素材信息顺序：素材标题、素材封面、素材简介、关联集数、正片连续裁剪、排序、上下架状态；状态单独放在最下方。
- 新增弹窗只回显当前合集名称和ID；删除下方短剧ID、锁定及推送状态提示，不展示独立「文件信息」模块。视频参数和默认封面仍自动读取，用于校验及提交。
- 「提交素材」全部校验通过后立即推送，无额外确认或保存后另行推送步骤。前置失败保留表单，不生成新素材。提交中阻止重复操作，完成后显示逐条结果。
- 二级页不提供「批量推送」「推送记录」按钮及批量勾选。失败或结果待确认项可直接重试，复用原素材ID和版本；成功项不展示重复推送入口。
- 默认按sort升序，表头切换升降序只影响查看。「调整排序」上移、下移当前合集全部素材，提交后按1起始设置sort，并立即推送变更项；取消不修改。
- 列表移除预览、删除和编辑，封面仅显示缩略图。操作按状态展示「上架」或「下架」，校验通过直接推送新的状态版本；保留原素材ID和历史成功版本。前置失败不改变状态，推送中禁止重复操作，未成功项可重试。
- 返回合集列表保留原筛选；同一页面内重新进入，已添加素材及状态保持。Demo不提供刷新后持久化。
- 所有上传与推送均在浏览器模拟，顶部独立原型工具栏可切换回执场景。样例内容为虚构，示例WebM为本项目生成的几何动画。

## 页面与说明

沿用工作区的产品原型说明标准，保持1560px原型画布、右侧520px说明栏（1440px及以下为440px），整体允许横向滚动。橙色序号点击定位对应说明，每页及独立弹窗重新从1开始。

说明仅覆盖本次新增及修改功能；已有筛选和列表字段不重复介绍、不标序号。菜单和四个合集池行操作沿用留存OPPO原型，合集信息弹窗按用户截图保留原六列及五个筛选项，末列新增添加素材。

## 验证

最新验证范围为列表旧操作移除、上下架成功与失败重试、前置拦截、防重复提交、排序及新增流程；布局检查1280×800、1440×900及2300×1000。证据位于工作区`output/playwright/oppo-material-status/`。

## 接口与发布

依据[主动推送文档](https://ivl58n9swia.feishu.cn/docx/IXuUdIiRSozRBXx6y3Pckir9n1c)第6节，2026-10-23已核对。接口为`POST /content/drama/push/material`；短剧须先推送成功，materialId全局唯一且不超过10字符，未进入successList的素材不认定成功。
