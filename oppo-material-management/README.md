# OPPO 合集池添加素材

主入口：合集池管理 → OPPO 行 → 更多 → 查看合集信息 → 合集行内「添加素材」。点击后锁定当前合集，直接上传本地视频。

“素材管理”为查看已存素材和推送结果的辅助入口。

预览地址：<https://hongjuan303.github.io/html-prototypes/oppo-material-management/>

## 交互范围

- 直接上传一个或多个本地视频，自动读取时长、分辨率、大小并截取默认封面。
- 逐条维护标题、简介、关联集数、连续裁剪的原片起始时间、排序、上下架状态与封面。
- 必填、15～480秒、720p及以上、单集连续裁剪条件和排序校验。
- 按短剧分组推送、前置短剧检查、下架、部分失败、漏回、超时、重试及版本记录。
- 顶部独立原型工具栏可切换模拟回执；所有上传与推送都在浏览器当前页面模拟，不向任何渠道传输文件。
- 样例内容为虚构；`sample-material.webm` 是本项目生成的几何动画，供视频预览使用。

## 页面与说明

保持1560px原型画布；右侧常驻说明为520px，1440px及以下窗口为440px，随整个画布横向滚动。序号点击定位说明，每页与独立弹窗重新从1开始；筛选、列表和主要操作按区域编号。

既有绿台菜单、四个合集池行操作沿用留存OPPO原型；查看合集信息弹窗按用户提供的线上截图对齐六个原有列表字段和五个筛选项，末列新增添加素材。未重新登录绿台生产系统。原有三个行操作为静态背景展示，本次可交互范围为素材功能。

## 验证

已检查1280×800、1440×900及2300×1000；验证合集行直达、合集只读、保存/取消回到原列表且保留筛选、实际视频解析与播放、必填及不合规时长拦截、0秒续播、多集不传起始时间、前置短剧阻止、部分成功、漏回、超时、仅重试未成功项、下架版本及历史记录。浏览器主流程无脚本异常。

## 接口依据

[OPPO短剧标准接入文档forCP 主动推送](https://ivl58n9swia.feishu.cn/docx/IXuUdIiRSozRBXx6y3Pckir9n1c)第6节，2026-10-23读取，页面显示10月13日修改。

请求：`POST /content/drama/push/material`。素材ID全局唯一且长度≤10，短剧须先推送成功；未进入`successList`的提交项不可认定成功。

接口未明确的全量或增量、数量上限、素材格式与大小、地址有效期、封面比例、文本长度以及`index`和`indexs`差异，保留为待确认项。
