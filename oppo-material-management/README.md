# OPPO 合集池添加素材

入口：合集池管理 → OPPO行更多 → 查看合集信息 → 合集行「添加素材」→ 当前合集二级素材页。列表展示已添加素材，工具栏右侧依次放置「新增素材」「调整排序」，数量信息保留在左侧。通过「新增素材」继续本地上传。

## 当前交互

- OPPO「查看合集信息」列表新增「编辑」，打开「编辑」弹窗，不展示重复的「传剧主信息」分区标题。合集ID和名称只读，新增必填日期「版权到期下架时间」，存储字段为`copyrightOfflineTime`，字符串格式`YYYYMMDD`。点击「确认推送」校验必填及日期有效性；失败保留表单并在字段下提示，通过后提交当前合集信息至OPPO平台，关闭编辑弹窗并toast「推送完成」，返回原合集列表、保留筛选和分页；取消、关闭、Esc均不保存。配置按合集独立回显，不写入素材列表。编辑弹窗右侧不展示「说明／演示范围」段落。
- 本地上传一个或多个视频，逐条维护标题、简介、关联集数、连续裁剪起始时间、排序、上下架状态和封面。不从现有素材库选择。
- 素材信息顺序：素材标题、素材封面、素材简介、关联集数、正片连续裁剪、排序、上下架状态；状态单独放在最下方。
- 新增弹窗只回显当前合集名称和ID；删除下方短剧ID、锁定及推送状态提示，不展示独立「文件信息」模块。视频参数和默认封面仍自动读取，用于校验及提交。
- 「提交素材」全部校验通过后立即推送，无额外确认或保存后另行推送步骤。前置失败保留表单，不生成新素材。提交中阻止重复操作，完成后显示逐条结果。
- 二级页不提供「批量推送」「推送记录」按钮及批量勾选，列表操作移除「重试」「提交」。页头不展示池类型和池名称组合文案。
- 默认按sort升序展示，列表排序表头仅显示字段名，取消升降序操作按钮。保留「调整排序」弹窗，通过上移、下移调整当前合集全部素材；提交后同步推送变更项，关闭弹窗，仅toast提示「排序已调整」，不展示结果弹窗；取消不修改。
- 列表不提供预览和编辑，封面仅显示缩略图。操作按状态展示「上架」或「下架」，校验通过直接推送新的状态版本；保留原素材ID和历史成功版本。前置失败不改变状态，推送中禁止重复操作。仅「推送失败」显示「删除」，确认后移除当前合集的本地视频素材和配置、释放上传视频资源，保留推送记录并提示「删除成功」；取消或关闭不删除，保留列表筛选并更新数量与分页。
- 列表「失败原因」紧接「推送状态」，然后是「最近推送时间」；无原因显示「—」，过长省略、悬停显示全文。
- 返回合集列表保留原筛选；同一页面内重新进入，已添加素材及状态保持。Demo不提供刷新后持久化。
- 所有上传与推送均在浏览器模拟，顶部独立原型工具栏可切换回执场景。样例内容为虚构，示例WebM为本项目生成的几何动画。
