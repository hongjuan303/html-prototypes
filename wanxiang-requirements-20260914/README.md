## Running

纯静态 Demo，使用 HTTP 本地服务打开，以便同源页面共享演示状态。已有 `8766` 服务时直接使用，不要重复启动或终止其他原型服务。

若服务尚未运行，可从 `html-prototypes` 目录启动：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

随后打开上表地址。前台、后台需使用同一浏览器及同一主机端口；不要混用 `localhost` 和 `127.0.0.1`，否则无法共享 localStorage 演示状态。

- 验证码固定为 `123456`，不发送短信，不连接正式鉴权服务。

- 前后台审核结果仅通过 localStorage 在本地模拟联动，不修改真实用户或业务数据。
- 海外资源与跨版行为不在本次文案改动范围，已有演示不作为新增功能需求。
- 商务资料沿用 QA 联系商务表单；不填造号码、二维码或联系人，不连接真实商务服务。
- 图片来源见 `assets/sources.json`。沿用当前 QA Logo，不擅自新增品牌方案或版权规则。
