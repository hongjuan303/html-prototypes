# 页面说明

本页是容量万相 9 月 14 日会议需求的原型说明，仅覆盖首页创作入口文案、海外入口文案、审核制登录、内容库查看更多及绿台「登录用户管理」五项。Logo 调整、海外剧本分集试读及资产库调整不属于本次 Demo 和需求范围。

背景：官网 UI 完全复制当前 QA，仅修改本次明确涉及的文案与功能；不调整任何未涉及的布局、样式或交互。

需求：只呈现会议提出的功能变化，验证前台手机号申请、绿台审核、审核通过后登录的完整关系。

业务依据：会议文档 · 9月14日　复用来源：容量万相 QA 官网

本次为交互演示原型。账号、验证码、审核与短信均为模拟；不连接真实注册、短信或权限服务，不改变 QA 数据。

3# 审核制登录

本弹窗是官网手机验证码登录入口，UI 沿用当前 QA；只有审核通过的手机号可完成登录。

填写项

字段形式规则
手机号文本输入必填；Demo 校验 11 位中国大陆手机号。作为登录审核记录的业务识别信息；登录页不增加业务资料填写项，资料沿用官网「联系商务」表单。
验证码文本输入、获取验证码必填；先校验手机号再获取验证码。Demo 使用 123456，未通过验证码校验不创建审核记录。
同意用户协议与隐私政策复选框沿用 QA 登录弹窗的必选项；勾选后方可提交。未勾选时提示先阅读并同意，不创建审核记录、不完成登录。

确认、取消与结果

状态 / 操作业务规则及页面反馈
审核通过验证码验证成功后正常登录，关闭弹窗并回到触发登录的页面；展示已登录状态。
尚未申请验证码验证成功后创建待审核记录，但不登录；保留当前登录页，在验证码下方以红字显示「暂无登录权限，联系商务获取。」。其中「联系商务」可点击并保持红色，点击打开 QA 原有商务表单；不另开权限弹窗或结果页。
待审核验证码验证成功后仍不可登录，留在当前登录页并显示同一条红字提示；Demo 复用该手机号的现有待审核记录，不重复新增。
已拒绝不允许登录，留在当前登录页并显示同一条红字提示；Demo 保留原拒绝结果，不自动重新发起审核。重新申请规则待确认。
校验失败手机号、验证码不符合规则或未勾选协议时，提示对应错误并保留弹窗及当前输入，不创建记录、不改变登录状态。
取消 / 关闭关闭弹窗，回到原页面与原浏览位置；不登录，不额外创建审核记录，也不改变内容的显示状态。此前已有效提交的待审核记录继续保留，不因关闭弹窗撤销。
登录页底部常驻文案始终显示「无法登录？联系商务」；「联系商务」可点击打开 QA 原有商务表单，无需先登录或触发错误。
联系商务底部常驻文案、现有浮动入口及无权限红字中的「联系商务」均打开 QA 原有表单。提交后按「联系方式」中的手机号关联并更新同一手机号申请详情；不虚构商务联系人、号码或二维码。

正式短信发送频控、验证码有效期、失败重试尚未明确；Demo 的验证码与本地状态不作为正式安全规则。

联系商务表单（沿用 QA）

表单文案「请留下合作需求，我们将在 1 个工作日内与您联系」。UI 原样复用 QA：姓名与公司、联系方式与职位分两列，合作方向及合作需求通栏展示。

字段形式填写规则
姓名文本输入必填，最多 30 字。
公司 / 机构名称文本输入必填，最多 60 字。
联系方式手机号输入必填，中国大陆 11 位手机号；占位文案「请输入手机号」。用于关联该手机号登录申请。
职位 / 角色下拉单选选填；企业负责人、内容负责人、制片人、导演、编剧、投资机构、政府或事业单位、其他。
合作方向下拉多选必填；IP版权合作、漫剧制作、AI工具/平台合作、内容发行与投流、海外发行、政企项目、其他。
合作需求多行文本必填，最多 500 字，实时显示字数。
  • 底部隐私政策及允许商务联系为必选勾选项，不作为后台详情的第七个业务字段。
  • 必填项、手机号格式或协议未通过校验时，保留表单并提示对应错误，不保存资料；取消或关闭不提交资料。
  • 提交仅在本地模拟。直接提交商务表单也会按联系方式手机号创建或更新同一条申请：没有记录时创建待审核记录，已有记录时更新六项资料，不重置既有审核状态，不因补充资料自动通过审核。成功提示提交结果；保存失败保留填写内容，允许重试。

4# 小说 IP 库 / 剧本库 · 查看更多

本页是小说 IP 库或剧本库的内容列表页，本次仅补充内容尾部「查看更多」模块与登录的关联。

  • 未登录时，内容尾部展示「查看更多」。点击打开同一套手机验证码登录弹窗。
  • 登录成功后隐藏当前内容库的「查看更多」模块；不在原型中擅自承诺新增条数、解锁作品或付费权益。
  • 未通过审核、校验失败或关闭弹窗时，保留原页面内容及「查看更多」模块。
  • 当前页面已有登录状态时，不重复展示登录引导模块。

5# 绿台 · 登录用户管理

本页是绿台「AI 漫剧系统 → AI 漫剧官网配置 → 登录用户管理」，用于查看手机号登录申请并审核登录权限。

数据来源：登录审核记录由官网手机号验证码验证，或直接提交联系商务表单产生；均按手机号创建或更新同一条申请。没有记录时创建待审核，已有记录仅更新商务资料，不重置既有审核状态。详情的六项资料来自官网 QA「联系商务」表单，以联系方式手机号关联；审核结果决定该手机号能否登录官网。

来源版本不再作为筛选、列表或详情字段。系统记录可继续支撑列表与审核，但不得混入申请详情。

1筛选项

筛选项形式规则
手机号文本输入按输入内容进行包含匹配，支持部分手机号；去除首尾空格，为空时不限制手机号。
审核状态下拉单选全部状态、待审核、已通过、已拒绝；默认全部状态。
申请日期开始日期、结束日期按申请时间的自然日筛选，包含起止日期；允许只填一端。开始日期晚于结束日期时提示错误，不执行查询。

2列表项与详情

字段含义及来源
手机号官网联系商务「联系方式」关联的申请手机号；尚未提交商务资料时，使用官网登录的手机号。
申请入口首次触发登录申请的入口，如顶部登录、小说 IP 库或剧本库的查看更多；由系统记录，不要求用户填写。
申请时间手机号首次生成当前申请记录的时间，由系统生成。
审核状态展示待审核、已通过或已拒绝；与列表筛选和登录判断一致。
短信通知展示未发送、已发送或发送失败；拒绝后显示无需发送。已发送与发送失败均明确标注模拟短信。
操作待审核记录展示「详情」「审核」；已通过、已拒绝记录仅展示「详情」。不直接展示通过或拒绝按钮。

列表默认按申请时间倒序；时间展示到分钟。每页默认 10 条，可选 10、20、50 条，支持上一页、下一页及页码切换；更改查询条件或每页条数后回到第一页。

详情字段（按表单顺序）数据来源与展示规则
姓名官网联系商务表单「姓名」。
公司 / 机构名称官网联系商务表单「公司 / 机构名称」。
联系方式官网联系商务表单「联系方式」；尚未提交商务资料时回退为申请登录手机号。
职位 / 角色官网联系商务表单「职位 / 角色」。
合作方向官网联系商务表单「合作方向」。
合作需求官网联系商务表单「合作需求」。

详情仅展示上述六项，与官网填写表单保持相同顺序和中文名称；未填写资料显示「—」，联系方式按上述规则回退。不展示来源、时间、审核状态、审核人、审核记录等系统字段，也不放置审核按钮。

3操作项

操作处理规则与反馈
查询 / 重置查询按当前条件组合过滤列表；重置清空手机号、起止日期并恢复全部状态。无结果时展示「暂无符合条件的用户」及重置筛选入口，不保留上次命中的数据。
详情打开该手机号对应的六项联系商务资料，仅供查看；关闭不改变资料或审核状态。
审核仅待审核记录可操作；打开审核弹窗，单选「审核通过」或「拒绝」。必选、默认不选；未选择时提示选择审核结果，不保存。
确认审核通过选择「审核通过」并确认后更新为已通过，手机号注册成功并发送可登录短信通知。Demo 仅模拟短信及本地状态更新，前台再次登录可成功；短信发送失败不回滚已通过状态，具体重试方式待确认。
确认拒绝选择「拒绝」并确认后更新为已拒绝，手机号仍不可登录，不发送通过通知；本次不额外增加拒绝原因填写项。
取消 / 关闭审核关闭审核弹窗并保持待审核，不触发状态变更或短信通知。
保存中暂时禁用确认、取消、关闭及审核结果选择，防止重复提交；展示「保存中…」。
处理完成关闭弹窗并同步更新列表；通过提示「审核通过，短信通知已模拟发送。」，拒绝提示「申请已拒绝，审核结果已保存。」。已完成的审核不可修改；再次打开详情仅可查看。
保存失败 / 重试保留审核弹窗及已选择的结果，审核状态不变；提示保存失败并提供重试，防止重复提交。Demo 可在演示工具中单次触发此状态，不属于正式业务控件。
其他页面已处理提交前检查最新状态；如果已完成审核，提示并展示最新结果，不重复执行。官网新申请与其他原型页面的审核结果同步至当前列表。
Demo 按手机号复用申请资料及审核状态；正式记录去重与拒绝后重新申请规则待确认。
