# 小小英语角

基于家长提供的 Level2 期末卷，为 4 岁孩子与家长提供英文点读、中文标注及游戏复习。

- 8 个主题，27 张原卷学习图，166 个词条，153 条原有问答与句子示例。
- 每张卡片关联具体问答，共 171 组。电脑端在卡片旁显示，手机端紧接当前卡片所在行展开；“本小节完整句型”仍可展开查阅。
- 每个词和句子保留中文标注，语音只播放英文，支持慢速和停止播放。
- 点读使用 410 段去重静态英式英文 MP3，无语音服务密钥；页面不加载中文音频。
- 听音选图每轮最多 5 题，允许重试；不会录音或自动评分。
- 十天复习方案、分日点读清单、词条星标与完成记录；仅保存在浏览器本机。
- 原图保持原内容；补充的完整回答标为情境示例，适当纠正原卷拼写和不严谨用法。

## 内容说明

英文采用家长试听确认的 Google Gemini TTS Lumi 女声，使用英式幼儿老师表达要求生成，包含自然的提问和鼓励语气。英文使用独立的 `assets/audio/en-gb-lumi-v1/` 路径，避免旧语音缓存。每条表达之间停顿 1000ms。单词、句子、整组问答和小游戏均只读英文，中文作为文字标注保留；旧版双语连读设置不再生效。页面播放预生成音频，家长使用时无需 Google 账号或 API key。英文加载失败会提示重试。没有广告、账号或儿童身份信息收集。

进入小节时预先下载一个包含本小节英文词句与卡片问答的音频包，减少逐段请求的网络等待。包内保存原始 MP3 字节，不重新编码或改变声音；就绪后使用本机 Blob 点读。最近 3 个小节保留在内存，已访问的音频包尽可能保存到浏览器缓存，文件名包含内容哈希以区分更新。缓存不可用或音频包下载失败时，仍可直接点读原音频。首次打开且尚未准备完成时仍可能等待网络。听音小游戏也会准备当前题目的所属小节。旧中文音频文件仅为已有缓存页面兼容保留，新版无中文播放入口。

维护音频后运行工作区 `output/kids-english-level2/build_audio_packs.py` 重建 27 个音频包和 `audio-packs.js`，再与页面一并发布。

卡片问答是按原卷句型为当前图片补全的练习示例。食物喜好保留肯定与否定两种答案；原有 153 条完整表达和原卷图片均保留。

家长带练方法参考 British Council 家庭英语启蒙建议：
https://learnenglishkids.britishcouncil.org/parents/helping-your-child/how-start-teaching-kids-english-home

词义均依据题图语境。特别说明：strong 与 beautiful 不是反义词；aunt、uncle、cousin 按家庭实际称谓翻译；原卷 Look and chose 的用词应为 Look and choose；in the nighttime 可用 at night 表达。
