# 混剪高光 V4 Demo

按国内与海外共用业务方案制作。2026-09-14 在 V4 增加绿台合集片源入口，不修改 V2/V3 或旧 PRD。

公开入口：https://hongjuan303.github.io/html-prototypes/ai-smart-mixed-cut-v4/

本地入口：http://127.0.0.1:8765/html-prototypes/ai-smart-mixed-cut-v4/

## 可体验内容

- “从绿台选择合集”：国内短剧 / 海外短剧枚举分别显示对应合集，支持名称或 ID 搜索、选择合集与起止集数配置。
- 区分总集数与可用片源集数；未选择、缺集、越界、空合集均不能应用。切换国内/海外会清空弹窗内待选合集，取消不改变当前片源。
- 合集与选集回填到制作页，并随任务和 JSON 保存来源；历史任务再制作复用其片源，剪辑预设不覆盖当前片源或选集。

- 前 10/20/30 集快选、自定义起止集及剧集网格。
- 原片混剪与 AI 解说 + 原片；短解说、约 30 秒组合、30–120 秒较长解说预设。
- 1–20 条、3–5/5–7 分钟以及约 1/3/5/10 分钟；原片与解说分别安排速度和时长。
- 字幕、BGM、引流标题可组合；合成旋律试听、浏览器解说试听、保存常用预设。
- 批次进度、失败与取消、只补生成未完成条目；示例钱包冻结、结算、释放与流水。
- 每条故事板、来源时间码、连续查看接点、人工确认与免费局部修复演示。
- 导出 JSON 方案、SRT 示例字幕，多条字幕打包 ZIP；本地视频文件仅做原片预览。

## 明确边界

所有剧集、剧情和质量状态都是虚构示例。页面没有真实 AI 分析、语音合成服务、语义质检或视频渲染；不能导出 MP4。浏览器语音试听与合成旋律均不代表生产音色或正式曲库。本地导入的文件不上传、不冒用示例剧情分析。

示例兑换比例为 100 积分 = ¥1，原片 30 积分/条、解说 60 积分/条，用于演示账务交互，不是正式定价。业务 0.6 元/可用条目标尚未实测达成。

本地状态存储在浏览器，仅属于本 Demo。刷新会终止模拟任务，保留已准备条目并释放未完成部分；真实产品应由服务器持续执行任务。可用左下角“演示设置”切换部分失败场景或重置演示。

## 界面方向

实用创作工作台：清楚、克制、可复用。沿用容量万相品牌，用中性色、青绿操作色和少量橙色提示区分内容与计费；右侧用剧照和时间线表达成片结构。配置分为选剧、制作方式、包装三组，固定底部展示报价和生成操作。结果用列表，便于批量检查。

流程参考来自已核对的[集思智效](https://drama.vibbit.cn/user/tasks)、[AIMIX](https://web.aimix.pro/)、[鬼手剪辑](https://cn.jollytoday.com/Short_Film_Narration/)、[短剪通](https://www.hzai.cc/)，不复制其品牌或宣传效果。

## 运行方式

从工作区根目录运行静态 HTTP 服务，并打开上述路径。资源均为目录相对路径，兼容既有 GitHub Pages 子目录规范。通过现有仓库 main 分支根目录发布，不新增 Pages 工作流。

内置 `assets/jszip.min.js` 来自已安装的 JSZip，用于多条 SRT 打包，保留文件内版权声明。

## 绿台接入边界（2026-09-14）

`sources.js` 为国内、海外两份虚构合集目录，演示相同合集 ID 在两套数据源中的隔离。列表、可用集数和封面均不是线上绿台读取结果；所有合集复用虚构剧情元数据，不能据此评估真实混剪质量。当前使用方只选择“国内短剧 / 海外短剧”，不需要输入绿台地址。

正式接入时由服务端按类型配置两套绿台地址和授权，提供对应合集搜索、剧集元数据及可用片源；身份使用“类型＋合集 ID＋集号”，提交生成前重新校验可用性与权限。历史展示读取提交时来源快照；真实请求需补齐加载、失败重试、失效处理及切换请求防串源。真实地址、授权方式和接口契约尚未提供，本次未做接口调用。
