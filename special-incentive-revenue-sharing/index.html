# 页面说明

  • 页面名称：专项激励配置
  • 菜单路径：绿台 ＞ 版权管理 ＞ 专项激励配置
  • 使用对象：版权、财务及结算业务
  • 需求背景：现有专项激励仅能归属一个业务方；新增激励可能由番茄、抖音原生共同享有，需要支持按比例分配。
  • 需求目标：兼容单方100%归属，同时支持两个业务方按50%/50%、60%/40%等比例分配。

# 原型说明

筛选

  • 账单月份、激励类型：沿用现有筛选逻辑。
  • 收益归属方：新增下拉筛选；选择业务方后，查询收益分配中包含该业务方的数据。
  • 导出：导出字段“收益归属”调整为“收益分配明细”，示例：番茄:50%;抖音原生:50%。

列表

  • 收益分配：原“收益归属”字段升级，展示业务方及分成比例；单方历史数据展示为“番茄 100%”。
  • 编辑：点击打开收益分配弹窗，账期及激励类型只读。

编辑弹窗

  • 收益归属方：下拉单选，枚举为番茄、抖音原生；同一业务方不可重复。
  • 分成比例：必填，单位%，支持最多2位小数，取值范围为0.01%～100%。
  • 添加收益归属：本期最多配置2个业务方；新增第二方时默认调整为50%/50%。
  • 删除：删除第二方后，保留业务方的比例自动恢复为100%。
  • 合计校验：所有分成比例必须合计100%，否则不能提交。
  • 保存确认：提交前二次展示账期、激励类型及调整后的收益分配。

# 业务规则

  • 计算公式：业务方收益 = 专项激励总收益 × 业务方分成比例。
  • 金额精度：按分计算并保留2位小数；尾差计入最后一个业务方，保证分配金额合计等于专项激励总收益。
  • 负向金额：退款、冲销、调账等负向金额沿用原比例反向分配。
  • 结算限制：已进入结算流程的账期不可修改，后端保存时需再次校验。
  • 唯一性：同一“账期 + 激励类型”仅保留一套有效收益分配方案。

# 数据兼容

  • 历史数据：现有单方归属数据迁移为“原业务方 + 100%”，已结算账期不重新计算。
  • 数据结构：后端采用收益分配明细数组，不新增固定的“番茄比例、抖音原生比例”字段，为后续增加业务方预留扩展能力。
  • 操作日志：记录操作人、操作时间、修改前和修改后的分配明细，支持财务追溯。

# 验收标准

  1. 支持单方100%和双方任意合计100%的分配方案。
  2. 比例合计不为100%、比例越界或业务方重复时无法保存。
  3. 列表、筛选、导出及下游结算使用同一份收益分配数据。
  4. 历史单方配置正常展示，已结算历史账单不受影响。
