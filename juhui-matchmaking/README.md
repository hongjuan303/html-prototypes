# 剧汇平台业务测试原型

[打开原型](https://hongjuan303.github.io/html-prototypes/juhui-matchmaking/)

版本：20261109-channels。平台端与供应商端、撮合与代发行均在同一原型内切换。

## 本次更新

- 渠道字典统一为业务确认的28项，权限配置与排期共用，保留旧授权及历史任务；聚合名称按独立枚举处理。

- 撮合概览合入平台【撮合管理】和两类供应商【内容管理】，状态直接筛选或跳转对应业务列表；支持返回恢复条件与终止合作历史查看。
- 用户权限分配区分撮合与代发行；本轮撮合概览及权限页面的需求说明在画布右侧，点击橙色编号可定位查看。
- 剧本和承制物料使用侧边目录与整份提交，核验与上传保持相同资料结构；核验意见、附件及历史版本可供提交方查看。
- 补齐剧本上传／审核历史与附件预览，承制方选中即进入开发中；合作终止直接回库待匹配。
- 独立流程图：[全流程泳道总图](./matchmaking-overview.html)、[分段泳道详图与节点角色](./matchmaking-swimlane.html)。

## 开始体验

1. 点击顶部【测试场景】，选择业务、流程和体验身份，再打开【样例1】或【样例2】。
2. 平台管理员可体验所有平台操作；切换具体演示人员可检查岗位权限。剧本方、承制方、代发行版权方可从场景窗口直接进入对应账号视角。
3. 剧名中【方括号】标识初始测试场景，不随操作更新；当前状态以列表和详情中的状态为准。可用剧名或ID搜索同一条记录。
4. 浏览器自动保存操作进度，刷新不会还原已处理记录。【重置示例】会清空该浏览器当前版本的测试修改与新建记录，并恢复全部初始场景。不同浏览器、不同访问域名的数据相互独立，不是多人同步系统。
5. 可[下载合成测试附件](./demo-assets/test-fixtures.zip)，用于文件上传、预览、下载、审核意见附件和物料补充。Word/PDF/Excel/图片均为原创合成测试资料；视频交付记录使用明确的占位文件，可自行上传本机测试视频。试看、上剧材料和上线链接指向测试资料页，不代表真实渠道发布。

## 数据与部署

- 新测试记录使用固定 `DEMO-M-` / `DEMO-D-` ID，只追加一次，不覆盖浏览器原记录、上传文件或历史状态。
- 静态原型，不连接正式业务接口；合同仅模拟文件留档，通知和数据拉取为演示。
- 发布文件不包含本地上传内容、真实Word样例、浏览器存储或账号密码。
- 使用仓库现有 GitHub Pages `main` 分支根目录发布；资源使用项目内相对地址，解析到 `/html-prototypes/juhui-matchmaking/`。
- 第三方依赖为本地Mammoth和SheetJS CE，许可证与来源信息在 `vendor/` 中保留。
