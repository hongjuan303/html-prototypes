## 已实现的演示交互

1. 选择素材直接打开OSS文件库，支持搜索、文件夹、跨页勾选及状态判断；不提供本地文件选择器，不要求业务类型或前置剧目。
2. 同一批素材可用于任意一个、两个或三个平台，账号与目标独立配置。
3. 抖音先选账号，再选其端上剧；视频号先账号及挂链类型，再选对应剧目。
4. 快手挂链类型单选【作者服务 / 通栏服务】。作者服务默认【关联变现任务】，通栏服务默认【关联短剧变现任务】；只选择当前分支的具体任务。
5. 快手作品描述默认 `#剧名#短剧题材`。选任务后带入示例剧名、题材生成描述，可直接修改作品描述；实际数据来源待接入，不单设剧名和题材输入。
6. 快手封面默认视频第一帧，作者声明默认【演绎情节，仅供娱乐】，发布时间单选立即发布/定时发布。
7. 更换快手类型提示清空任务及描述变量，取消保留；确认后重选。候选按账号及类型隔离，失效任务禁选，定时任务按计划时间验证有效期。
8. 确认页按素材×账号计算任务；一个快手明细只包含一种服务关联。详情、筛选与导出支持快手任务字段。
9. 只提交通过项后，草稿保留问题明细，已成功提交项不重复生成。旧双平台草稿保留原平台选择并补全快手可用配置。

## 推荐评审路径

新增发视频 → OSS选两份素材 → 在上下排列的平台区块中选择账号并编辑素材 → 单选挂链类型并选择目标 → 核对作品描述与默认字段 → 用「同步信息」批量应用至勾选素材 → 确认发布明细 → 模拟提交 → 详情查看实际配置。

可试验切换快手类型、只批量配置一份素材、缺少任务或描述变量，以及计划时间超出任务有效期。
