# 腾讯视频合集池管理需求原型

原型地址：https://hongjuan303.github.io/html-prototypes/tencent-video-collection-pool/

静态交互原型，无真实接口调用。使用虚构合集、CID、文件与回执；草稿和模拟结果仅保存在当前浏览器的独立localStorage命名空间。

范围：腾讯池配置、池内合集、版权材料类型多选与腾讯文件编辑、图片/PDF附件、条件材料、合集级推送、阶段记录。分集来自已有合集；推送自动完成素材上传、创建专辑、批量提交，不单独新增分集管理页面。

编辑页补充横版/竖版/火龙榜单封面、已映射角色的剧照及条件证明文件。自有版权材料可多选协议声明、版权证书、个人承诺函＋版权补充材料，按勾选展开并校验；取消勾选保留文件但不参与推送。无自有版权固定为版权链。兼容既有单一路径草稿，类型与文件一并保存在本地。是否重点备案由业务单选是/否，初始带入现有值；其余字段从合集列表映射，不重复填写。合集信息页筛选删除内容品类，列表删除内容品类/总集数/腾讯CID；行操作仅保留编辑，移除单条及批量重新推送。

默认图片：竖版封面取绿台合集列表封面，角色剧照取对应演员照片；展示来源提示，可预览、更换和移除。已有手动选择优先，主动清空不自动补回；源照片缺失时手动上传。保存不回写合集封面或演员照片，角色名称、数量及顺序不变。

条件文件：编辑页新增是否重点备案必填单选，业务选是时上线备案文件展示且必传，选否时隐藏；切换保留已选文件。IP改编文件仅在绿台合集“内容来源”为“IP改编”时展示且必传，与内容品类及旧IP标志无关。其他情况隐藏且不参与校验和提交。是否重点备案随腾讯资料保存，不回写源合集；备案号及内容来源由合集映射，内容来源本页不提供切换。右侧说明始终列出完整显示/隐藏规则。默认评审样例900321的内容来源为IP改编、重点备案初始为是，已保存选择优先；旧浏览器样例仅增量调整其映射并补新文件槽位，不覆盖既有文件、版权勾选或提交记录。

2026-10-27用户已明确授权将当前修订发布至现有GitHub Pages目录；后续修改仍默认先本地预览，发布须获得当次授权。

版权类型选择参考快手短剧上传的交互：标签式多选下拉，已选项显示为可移除标签，下方按类型展开材料区；PDF卡片支持预览、移除、更换或追加。材料类型及PDF规则沿用腾讯当前约定，不套用参考图的图片格式或大小限制。无自有版权固定版权链。取消类型保留文件，重新选择恢复；保存回显类型与文件。右侧已移除指定的版权多选边界提示及需求评审版日期文案。

合集信息页已移除单条及批量重新推送、批量校验、推送记录、修改池元素入口及表格上方的素材来源说明；已选数量放在表格标题右侧。编辑页底部确认推送保留既有本地保存与返回列表交互。

右侧说明随当前页、弹窗切换，每页独立编号；橙色标记可定位对应说明。原型1560px，说明520px（较窄窗口440px），整体横向滚动。

顶部回执演示切换正常接收、素材失败、CID超时、分集明确未受理和分集超时。批量演示只将异常注入第一个合集，其余继续执行。结果待确认禁止直接重试，已有CID复用。成功仅表示接口接收。

当前PDF材料路径为拟定规则；材料槽位的图片兼容范围、自有版权路径、非AI声明枚举、幂等、部分成功、集序、审核与上线查询需腾讯确认。非AI短番允许存草稿，暂阻断推送。未提供真实密钥配置入口。

本地启动：在父工作区目录运行 `python3 -m http.server 8769`，访问 `http://localhost:8769/html-prototypes/tencent-video-collection-pool/`。资源使用GitHub Pages规定的绝对基础路径。

提交状态仅为未提交、提交中、提交成功、提交失败；资料完整性单独显示。超时仍保持提交中并保留待核实阶段，核实前阻断重复执行。旧状态自动兼容，不重置草稿、CID或文件。

每行仅展示蓝色的编辑，不隐藏或置灰；所有合集均可编辑本地材料。状态查询筛选可实际生效。提交状态后新增提交失败原因列：失败时取最近一次明确失败记录，展示阶段和原因；其他三种状态显示“—”，失败记录没有原因时显示“暂无失败原因”。长文本自动换行，接口内容转义后展示。2026-10-28用户已授权将删除重新推送及新增失败原因列的当前修订发布至原GitHub Pages目录。
