# 腾讯视频合集池管理需求原型

发布地址：https://hongjuan303.github.io/html-prototypes/tencent-video-collection-pool/

静态交互原型，无真实接口调用。使用虚构合集、CID、文件与回执；草稿和模拟结果仅保存在当前浏览器的独立localStorage命名空间。

范围：腾讯池配置、池内合集、四步专辑资料、图片/PDF附件、条件材料、合集级推送、阶段记录。分集来自已有合集；推送自动完成素材上传、创建专辑、批量提交，不单独新增分集管理页面。

右侧说明随当前页、步骤、弹窗切换，每页独立编号；橙色标记可定位对应说明。原型1560px，说明520px（较窄窗口440px），整体横向滚动。

顶部回执演示切换正常接收、素材失败、CID超时、分集明确未受理和分集超时。批量演示只将异常注入第一个合集，其余继续执行。结果待确认禁止直接重试，已有CID复用。成功仅表示接口接收。

当前PDF材料路径为拟定规则；材料槽位的图片兼容范围、自有版权路径、非AI声明枚举、幂等、部分成功、集序、审核与上线查询需腾讯确认。非AI短番允许存草稿，暂阻断推送。未提供真实密钥配置入口。

本地启动：在父工作区目录运行 `python3 -m http.server 8769`，访问 `http://localhost:8769/html-prototypes/tencent-video-collection-pool/`。资源使用GitHub Pages规定的绝对基础路径。
