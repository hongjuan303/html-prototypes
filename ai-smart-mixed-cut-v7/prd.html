智能混剪 V7 需求评审说明#

2026-10-09 · 原型与编号说明

面向国内、海外短剧投放剪辑。评审按页面和橙色序号讨论。原型右侧按“页面说明＋原型说明”展示页面路径、作用，以及字段定义、枚举、数据源、操作和测试预期；相关产品规则直接展示在对应位置。待定参数放在附录。

01. 范围与主流程#

容量万相工具箱新增“智能混剪”，点击新开页面，沿用平台账户、权限和积分。三个菜单分工：剧目管理负责输入原片与只读计数；制作素材负责参数与生成；成片管理集中处理任务、输出与交付。主链路：剧目管理选原片 → 制作素材 → 成片管理。

1.1 高光混剪业务流程#

绿台来源决定交付系统；本地类型未知时先选择目标。只有当前版本人工确认后才能同步。AI 解说复用此流程，在编排后增加写稿、画面匹配和配音。

1.2 制作方式#

制作方式内容与声音
高光混剪提炼重要剧情，保留原声、完整对白、必要铺垫和悬念
AI 解说：解说＋原片解说引入或承接剧情，原片段保留人声；原片为主
AI 解说：全解说完整口播贯穿，原片提供对应画面，原片音轨静音

AI 解说首次必须选择结构；不默认短解说。内容分析与编排在生成流程内完成。投放回传评分、自动学习团队偏好不在本版；V6 保留供对照。

02. 制作素材#

配置展示与规则
片源与权限登录账号按稳定身份匹配内部员工。有国内/海外授权才可选对应绿台；单授权直接该源，双授权才可切。未匹配员工/无授权仅本地上传。后端复核合集查询、视频读取与生成，不凭语言/姓名/部门或前端参数推断；取消保留原片源
集数前10/20/30集或起止集数；正整数、起始≤结束、不越界、不含缺集/未准备集。合集搜索支持名称或ID
本地上传支持一次选择多个视频，展示集序、文件名、时长、大小与状态；可继续添加、删除、上下调序。重复文件跳过提示，失败项重试或删除，全部有效后确认导入；取消保留原片源。每个视频作为一集，类型未知，交付时再选国内/海外
本地追加已确认本地片源卡显示“添加视频”，绿台不显示。已有列表只读，新增尾部追加且仅新增可增删调序；按名称/大小/修改时间判重，旧元数据无修改时间时回退名称＋大小。确认N>0全有效后沿用同一资产/名称/封面/类型/既有视频ID，整体版本＋1、集数更新，不增任务/成片、不改历史快照。start保留，end原等于旧总集数则扩至新总集数，否则保留；取消/失败不改原片源
条数1–20条；5/10/20快捷项，支持输入、加减
最终成片时长高光/混合：约1/3/5/10分钟、3–5/5–7分钟；全解说：约30/60/90/120秒、3/5/10分钟、3–5/5–7分钟。按速度处理后的实际总长计算
成片速度0.8/1/1.1/1.2/1.5×。高光用于原片，全解说用于口播，混合默认共同生效
单独解说语速仅混合可勾选展开；首次1×，保留覆盖值。关闭恢复共同速度，再开启恢复覆盖；切换全解说只用成片速度
解说长度与位置长度自动安排，不设口播时长字段；混合可选开头引入或剧情中承接。切换结构保留各自最终时长
字幕高光/混合关闭新增字幕时保留原字幕；全解说控制新增解说字幕。字幕与最终人声对齐
BGM勾选即打开选曲；确认才开启，取消保留原状态。支持自动匹配或选曲；更换取消不覆盖旧选择
引流小标题勾选即显示输入框；去首尾空格后必填、最多24字。关闭保留文字但不用于成片；避开字幕
预计成片结构随配置更新数量、时长、声音、速度、BGM、字幕及标题；具体片段生成后查看

2.1 “生成视频”的系统处理#

点击后自动完成以下步骤，不增加必经的内容方案页。语音识别、视觉语言、剧情编排及语音合成分别提供内容分析或声音；原片切拼、变速、字幕和音轨合成由常规剪辑渲染服务执行。具体模型品牌和参数由研发按样片、耗时及成本选型。

阶段 / 执行者输入、处理及输出关键验收
1. 提交 / 业务与调度服务读取已确认本地资产或对应绿台所选集及配置，复核权限/片源/余额，锁定配置、源版本、标准和费用快照，分配唯一请求ID。绿台按来源、资产、源版本、语言及兼容分析版本复用；本地按稳定视频ID/指纹与兼容分析版本复用，新增集补分析未确认上传/缺集/无权限/余额不足不处理；同请求重试不重复任务与扣费，只处理所选集
2. 素材识别 / ASR、视觉语言、镜头检测拆镜头/关键帧，识别原声完整对白、说话人及句段时间码，结合字幕/OCR核对人物、场景与动作，生成有原片定位的分析记录不要求业务提供剧本或人物资料；对白、画面和集数/时间码可回查，识别不确定不编造
3. 剧情整合 / 剧情理解模型先按集/片段识别归纳，再按本次选集序整合人物关系、事件因果、冲突、铺垫、反转与悬念；输出规范化事实/高光候选，来源时间码和分析/标准版本贯穿编排不纳入选集范围外剧情，不颠倒因果；候选保留完整对白及必要上下文
4. 高光编排 / 编排模型与排重规则高光开场→因果承接→冲突升级→悬念收尾，删除冗长过渡/重复。结合时长、速度安排每条入出点；按事件、开头/结尾、区间、叙事角度排重，输出候选数量M不切半句、不拼出不存在的事实；只换BGM/标题/速度不算新内容；不足先确认实际数量，不凑条数
5. 解说 / 事实约束写稿＋TTS高光跳过。混合按前置/穿插位置写稿接完整原声，原片为主；全解说按目标时长/速度规划全文并匹配画面，原片静音。合成后依据实际音频时长回校准段落、画面和字幕文案仅依据所选集事实；解说与画面相符、接原声不吞字，按结构/时长动态规划口播，不设短解说默认上限
6. 合成 / 剪辑渲染服务按时间线真实切拼、变速保音调及声画同步，输出MP4和最终时间线；字幕对齐人声，BGM从广告可用曲库按情绪匹配并避让人声，小标题避字幕实际总长、速度及包装与配置一致；不在达标成片上再次整体变速
7. 检查 / 规则、音视频检测与模型抽查检查新增黑屏/冻结、吞字、声画/字幕同步、事实因果、解说衔接/图文、时长、重复和包装，输出逐条结果及问题位置；系统问题免费补救后复验修复作用于实际媒体；仍不合格不作为成功交付结算；不确定明确待处理，结果展示缺陷证据和时间区间，不引入投放回传评分
8. 交付 / 文件、计费与任务服务逐条保存可播下载MP4、状态、版本、费用和来源依据，进入成片管理，支持预览/反馈/返工/确认/下载/同步文件/播放器/时长/版本一致；生成不自动同步，人工确认当前版本后才按来源路由，未知本地先选国内/海外

生成按钮先校验配置与片源，错误说明原因并禁用；点击提交时复核余额。新增有效分析完成后结算，复用不收费；实际确认制作数量后冻结额度，逐条成功结算、失败释放，内部重试不重复扣费。

数量充足直接创建任务并进入成片管理。数量不足先展示请求N条、可生成M条、原因、已分析费及M条制作费；用户返回调整或确认生成M条。M=0不建任务、不收制作费；已完成有效分析保留。

03. 剧目与成片管理#

页面 / 操作规则
剧目列表管理输入原片，同源同合集归集，国内/海外及独立本地资产不按同名合并。仅搜索与来源筛选；来源为全部来源、国内短剧、海外短剧、本地上传，无汇总信息或状态筛选
剧目名称与封面绿台使用合集名称和封面；本地默认使用确认上传列表第一个文件名及其第一帧，黑屏时取首个有效画面
剧目计数集数为合集总集数或本地上传视频总数；任务为成功创建的制作任务数，失败重试不加；成片为所有任务实际生成的独立素材数，返工历史版本不重复计数
查看跳转成片管理，按稳定剧目身份自动填入筛选并显示当前名称，方式/素材状态恢复全部；跨任务所有素材平铺，无素材时保留筛选与制作入口。不改变正在制作的配置
新建剪辑进入制作素材并预选当前剧目，不直接启动分析或生成
重命名仅本地剧目展示；去首尾空格后1–80字。更新剧目列表、素材行及筛选显示名称，不改原文件名、历史任务和同步快照；取消不改
成片筛选剧目、制作方式、素材状态取交集。方式只有高光、AI解说，历史原片归入高光。状态为全部状态、制作中、待确认、制作失败，逐素材判断；同步失败不等于制作失败
素材列表每条素材一行，按任务创建时间倒序、同任务按素材序号排列。列为选择、素材、剧目名称、时长、素材同步、操作；无剧目汇总、任务组或展开层级，无检查按钮/检查状态列
剧目名称列使用关联剧目当前名称：绿台目录或本地重命名为权威。暂不可读取时可用历史名称临时展示；始终按身份关联，不用显示名称合并资产。源配置和同步快照保留
预览 / 确认可用仅被点击素材进入预览或人工确认；预览返回保留原筛选。制作中、失败、质量问题在名称下短提示；正常项不重复显示检查状态
单条返工 / 补生成只处理被点击素材，保留所属任务的片源、配置、标准和分析绑定。质量补救核验后免费，创作调整先报价；失败补生成不新增任务、不重做成功项
同步 / 记录只读当前行的任务、素材和内容版本；未确认禁止同步，成功看记录，未知先查询，明确失败仅重试失败项
取消这条制作仅制作尚未完成素材直接展示；停止当前条并释放其未结算冻结额度，同任务其他条继续、成功条保留，晚到结果不得重复交付或扣费
批量选择一次只选择同一制作任务内素材。点击另一任务素材时清原选择并提示切任务；全选只选当前操作任务、当前筛选内可选素材。切筛选或离页清选，平铺不代表跨任务提交
批量确认 / 同步 / 导出只操作当前已选集合，提交复核权限、质量、草稿、锁与当前版本；已确认未同步快捷选择只勾选不筛选。JSON仅辅助，主要交付为MP4

04. 预览与问题反馈#

4.1 成片详情与确认#

  • 左侧播放和进度定位，播放器下方仅一个“反馈问题”；右侧显示反馈记录，空态“暂无反馈”。不要求剪辑逐项读接点、完整结构、选取依据或包装说明。必要系统逻辑在原型右侧需求说明中展示。

  • 同任务可预览素材组成固定队列，从被点击条开始；后完成项不插队。切换素材归零，各条草稿保留；返回成片管理保留原筛选。稍后处理不确认、不生成。

  • 高光不可编辑原片台词。AI解说可按需展开“解说文案”，混合只改口播，全解说逐段修改，定位共用播放器。输入及“保存草稿”不改MP4/配音/字幕/版本、免费；未应用不能确认或同步。“试听文案”可使用当前有效编辑稿，免费，不保存、不升版。

  • 草稿状态只在顶部以只读文案显示。解说编辑区底部集中试听与三项修改操作：放弃修改为文字按钮，保存草稿为次按钮，应用修改为主按钮。无修改三项禁用；有效未保存时仅保存/放弃可用，已保存未应用时仅应用/放弃可用；输入实时刷新，处理中/同步锁全部禁用。

  • “应用修改”先打开报价，核对已保存且与编辑一致的稿和费用，再授权本条TTS、字幕、画面对齐及合成重制。成功升版撤销旧确认，重新人工确认；失败/中断保留旧媒体、旧确认记录与草稿并释放未结算额度。不能一概清空其它未解决反馈；旧同步快照保留。

  • 质量反馈可定位并核验补救，创作反馈先报价返工或接受当前版；记录不等于已修复、不自动训练。无高相似时不占位，命中才简短提醒并可查看相关视频、返回原素材，保持进度/草稿/队列；后台排重和原片事实时间码保留。

  • 人工确认必须主动勾选并绑定当前媒体版。确认并下一条进入下条，确认并同步先确认后打开上传；取消上传保留确认，队尾显示本轮结果。MP4播放/下载及国内海外交付要求保留。

4.2 时间段反馈#

入口：播放器下方“反馈问题”。打开暂停播放，按制作结构及包装显示适用类型；反馈记录区不重复放入口。

范围 / 输入校验
局部片段起始必填，默认当前进度；结束选填，填写时须晚于起始且不超过总时长。支持分:秒、小数秒或直接秒数；非法/越界拦截
整条素材隐藏时间输入，范围为0至总时长；切回局部保留输入。未填结束只记录起始位置
说明与判重说明选填、最多200字；同类相同范围不重复，不同范围可分别记录。取消不写入、不扣费

24项分为18项质量、6项创作；解说专属项仅适用结构显示，BGM/标题项随开关展示。

分类问题类型
质量：剧情/解说对白吞字、剧情不连贯/缺铺垫、成片内重复、解说缺句、事实错误、人物称呼/关系错误、解说原片衔接不自然、图文不符
质量：字幕/声音字幕错漏字、缺失/不同步、遮挡；配音读音错误、人声缺失/爆音/音量异常、BGM压人声、BGM缺失
质量：画面/标题黑屏/画面缺失、卡帧/闪帧、小标题遮挡
创作调整开场不吸引、节奏/速度不合适、结尾悬念不足、解说风格、BGM情绪、与其他成片相似

质量反馈进入待处理并撤销确认，阻止交付；创作调整独立记录、撤销确认，但不判系统质量失败，可确认采用当前版或报价后重做。两类记录均不修改媒体/升版，实际修改成功后升版并重新确认；核验为系统问题的补救免费，创作重做先报价确认。

05. 同步素材管理#

国内绿台自动进入容量广告，海外绿台自动进入容量海外短剧；本地未知类型先选国内或海外，不以员工绿台授权或视频语言猜目标。默认提交当前或本任务已选成片，不设置上传区域。

国内：五项必填默认、操作与数据源
上传目录单选；容量广告 → 上传素材 → 目录；只取当前账号有权限的有效目录
设计师默认当前账号按稳定身份映射，未匹配留空显式选择；可下拉改单人。容量广告 → 上传素材 → 设计师，不选第一项或复用他人
关联剧集默认当前剧目名称（含本地重命名），可直接编辑文本；不要求额外剧集ID
素材标签至少一个有效标签，可多选/按权限管理；容量广告 → 上传素材 → 素材标签
上线时间每次新同步默认上海当天，YYYY-MM-DD日精度，只能今天及以后；提交后端再次计算当日校验，跨午夜须更新过期值
海外：三项必填默认、操作与数据源

06. 共用规则#

6.1 R-01 片源与交付#

接真实绿台、本地批量片源，交付可播放/下载的MP4。默认保留画幅方向，最高1080p；编码、大小验证两套素材系统。JSON/SRT仅辅助。

6.2 R-02 内容质量#

完整对白、事实与因果连贯、人声清晰、字幕对齐、无剪辑新增黑屏卡帧是质量底线；解说须匹配画面并与原声自然衔接。业务用国内/海外及三种结构的好坏样片验收，自动检查不替代人工确认。

6.3 R-03 时长与速度#

按最终总长编排原片、口播、字幕及BGM，不在达标成片上再次整体变速。混合自动安排解说并保持原片为主；全解说按目标与语速规划完整文案。完整句/事实优先，不足时调整片源或时长，不硬截句、异常加速或凑内容。

6.4 R-04 内容差异#

综合剧情事件、开场、结尾、区间及叙事角度；全解说增加文案语义/顺序。同事件可保留不同剪法，只换BGM/标题/速度不算新方向。同批排重、避开同片源历史完全重复；不足按实际数量确认生成，不承诺每批20条互异。

6.5 R-05 声音与字幕#

默认按源语言制作，语种/音色需样片确认。全解说静音原片整轨；BGM避让人声，AI解说默认开启，主动关闭例外待确认。保留烧录字幕，新增字幕对齐人声；冲突处理不默认承诺擦字。

6.6 R-06 确认与内容版本#

确认条件：已生成、无质量问题、无未应用草稿、无修复/返工或同步锁定。输入/保存草稿及试听文案均免费、不升媒体版本；应用修改需已保存稿与编辑一致，先核对本条范围、文案和费用再授权。成功重制受影响配音/字幕/画面后升版、撤销旧确认；失败或中断保留旧片、旧确认记录及草稿，释放未结算额度。反馈/撤销反馈不升版，关闭问题不自动恢复确认。

6.7 R-07 补救与创作返工#

核验为系统质量问题的局部/整条补救免费，无法交付退该条制作费；创作重做先报价再确认。只重做本条，成功升版重新确认，失败保留旧片；不影响其他成片或旧同步记录。不能仅凭用户选质量枚举取得免费创作重做。

6.8 R-08 积分结算#

分析前展示最高报价并校验余额；有效新增分析完成结算，复用不重复收费。正式取消按有效完成部分结算，未完成不收。制作/创作返工先冻结，成功结算，失败/取消释放；内部重试不重复扣费。已扣退款与未扣释放分开，实际费用不超过授权上限。草稿暂存、有效复用、同步不收制作费。

6.9 R-09 账户与同步资格#

沿用主平台账户、扣费主体和角色；绿台访问由登录账号匹配内部员工及来源授权，单授权只读对应源、双授权可切，未匹配/无授权仅本地。后端校验合集、文件及生成，历史自有成片保留查看；同步另校验目标操作权限和对应字段schema，不因源授权猜本地目标。确认绑定当前版本，同步以版本防重；提交快照/回执可追溯，旧版不会被编辑或新同步撤回。存储期限由平台确定。

6.10 R-10 后台任务与异常#

任务在后台执行，关闭页面/熄屏不取消。逐条完成可预览；自动检查、可修复补救后再交人工，不确定项明确待处理，不合格不结算为成功。失败只补失败项，取消保留成功项及有效分析，释放未交付额度；未知同步结果按第05节处理。

6.11 R-11 分析与标准版本#

绿台按来源、资产、原片版本及语言复用分析；本地按稳定视频ID/文件指纹、语言及兼容分析版本复用，尾部追加升整体版本不使既有未改集重新分析。内部候选附原片区间和事实依据，新集数补分析；版本更新后未开工规划重新计算，进行中/历史保留快照，失败补生成沿原批依据。业务定义标准，产品整理规则，研发版本化并用样片回归后生效；反馈不自动训练或修改团队标准，可追溯/回退。
