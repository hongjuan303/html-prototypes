人员权限的关联渠道沿用线上26项具体发行渠道；支持渠道岗位搜索多选及必填校验，单独展示和保存五类质量评估职责，不使用供应商意向作为关联渠道。筛选与列表回显读取同一配置。

供应商管理保留列表工具栏【新建供应商】，新建和编辑弹窗均有供应商名称；名称与新建账号20字，登录账号仅新建可填写，编辑置灰只读并在保存时保留原账号，初始密码新建必填，负责商务／手机号／白名单同表配置，手机号非必填，可留空或清空；填写时校验11位有效格式和唯一性，账号仍校验唯一性。

内容评估保持同一菜单两个Tab，全量筛选后分页。质量评估列表按【国内渠道、仅微信视频号、YouTube、TT端原生、TT小程序】顺序增加五列，显示本轮各渠道任务状态及评估人，同渠道多人分别展示，未参与为“—”、已选择但未分配为“未分配”。本人任务汇总及操作权限保持，宽表横向滚动。当前处理人员可切换商务身份，满足条件时从质量评估列表【最终反馈】填写，结果与商务菜单同步；通过不可撤回、驳回可撤回。供应商白名单的新提交直接进入内容评估，其他按实际意向分派质量评估；国内新增仅微信视频号及其评估职责。提交弹窗的国内设置统一命名【国内发行范围】，仅微信视频号与三个不含选项同级两列展示，互斥切换时保持所有选项可见。两类渠道意见可撤回，商务通过不可撤回／驳回可撤回，审核记录保留完整文字意见和人员。

内容评估列表在集数后新增【首次提审】枚举是／否：首次为是，内容评估驳回后实际重提为否；仅质量评估重提、尚未重提或取消不改变。已补齐仅改集数复用A/B意见、综合结果前改意见、重提标签；正片提交同时选实际渠道并查看质量／商务意见，与商务确认并行，双方完成才开放物料并锁定渠道。商务操作四按钮和负责人修改归属有保存层校验。真人合同隐藏及默认有已由最新文档移入v1.3，TikTok例外按端原生、混选逐渠道演示；仅微信与排除项互斥为原型方案。未带回v1.4代运营、采集和字段配置模块。

仍待核：黄标物料表、海外梗概与B站图片关联、历史内部渠道ID映射、TikTok例外与混选细则。正式登录／文件服务及全菜单真实数据仍未完整接入；不把未确认细则或原型建议写成已定规则。原有合集、草稿、配置及附件不重置。

已保留排播口径：双审通过且有授权书后进入排播；供应商首发时间与平台上线时间共用同一值；供应商填写后，转免时间默认与首发时间一致，排播负责人只需确认，无需再填两项时间；未填首发时间仍由排播补充。单独维护过的转免时间保留，默认值随供应商修改的首发时间同步，原有日期精度及已有时分保持。渠道列表及右侧说明继续沿用用户的展示约定，新增字段橙色、橙底白字区域号，520／440px说明和1280px产品宽度保持。
